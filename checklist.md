# Чек-лист: загрузчик с пагинацией

Шесть вопросов к любому скрипту, который забирает данные из API страницами. Каждый - из урока модуля 1.

1. Как API сообщает о конце списка и что сделает загрузчик, если сигнал не придет? (1.1)
2. Есть ли предел числа запросов и падает ли загрузчик с ошибкой, когда он исчерпан? (1.1)
3. Попадает ли в результат последняя неполная страница? (1.1)
4. Обход идет по номеру позиции или по закладке? Если по номеру - может ли пройденная часть списка измениться во время обхода? (1.2)
5. Если по закладке - уникально и неизменно ли поле, по которому сортирует API? (1.3)
6. Записывает ли загрузчик трассу и сверяет ли он число полученных записей с тем, что сообщил API? (1.4)

Ответ "не знаю" на любой вопрос - повод открыть трассу.
