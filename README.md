# Тренажер сбоев пагинации API

Код к бесплатному практикуму "Пагинация API на Python: найдите потери, дубли и бесконечный цикл".

Загрузчик забрал данные из API, ошибок нет, в логе "готово" - а одной записи в базе не хватает и еще одна пришла дважды. Здесь четыре таких инцидента и тренажер, который прогоняет ваши решения через 29 сценариев.

Нужен только Python 3.8 или новее. Без установки пакетов, без интернета: учебный API работает в памяти.

## Быстрый старт

```
git clone https://github.com/Corner324/pagination-trainer
cd pagination-trainer/code
python trainer.py
```

Сначала отчет будет почти весь в провалах - задания еще не решены:

```
Тренажер сбоев "ВелоКруга"

Инцидент 1. Обход по страницам: когда остановиться  -  3 из 6
  [прошел] поездок нет
  [ПРОВАЛ] одна неполная страница
  [прошел] ровно две полные страницы
  [ПРОВАЛ] последняя страница неполная
  [прошел] limit=1
  [ПРОВАЛ] API за концом списка повторяет последнюю страницу
...
Итог: пройдено 4 из 29 сценариев.
```

Цель - 29 из 29. Что именно пошло не так в каждом сценарии: `python trainer.py -v`.

## Четыре инцидента

| Папка | Инцидент | Что делать |
|-------|----------|------------|
| `code/m1_l1_naive` | Загрузчик иногда теряет последние записи, а однажды не остановился | Починить `fetch_all` в `task.py` |
| `code/m1_l2_offset` | Одна запись пришла дважды, другая не пришла вовсе, ошибок нет | Написать `diff_trace`: найти потери и дубли по трассе запросов |
| `code/m1_l3_cursor` | Загрузчик перевели на курсор, он отработал без ошибок и забрал половину | Починить `fetch_all` в `task.py` |
| `code/m1_l4_trace` | В базе меньше записей, чем сообщил API | Написать `check_trace`: четыре проверки трассы обхода |

Условие каждого задания - в начале файла `task.py`. Объяснения, схемы и разбор - в уроках курса на Stepik (ссылка появится здесь после публикации курса).

## Как проверять

Одно задание, из папки урока:

```
cd code/m1_l1_naive
python -m unittest
```

Все сразу, из папки `code`:

```
python trainer.py
python trainer.py -v
```

В папках инцидентов 1-3 есть `demo.py` - он показывает сбой на экране:

```
cd code/m1_l2_offset
python demo.py
```

## Что внутри

- `velokrug.py` в каждой папке - учебный API выдуманной сети велопроката "ВелоКруг". Умеет менять данные прямо во время обхода, повторять последнюю страницу и не обращать внимания на курсор.
- `scenarios.py` - сценарии сбоев для задания.
- `test_task.py` - запуск сценариев через unittest.
- `trainer.py` - общий отчет по всем заданиям.
- `checklist.md` - шесть вопросов к любому загрузчику с пагинацией.

## Границы

Тренажер проверяет учебные функции на учебном API. Отчет "29 из 29" говорит о его сценариях и не доказывает, что рабочий загрузчик переживет любой сбой любого API.

Для проверки трасс настоящих API есть отдельный инструмент того же автора: [PageTrace](https://github.com/Corner324/PageTrace).
